# Test fixtures

Data for differential tests that use GNU sed output as the reference.

- `script.sed` and `input.bin` are written for this project. No GNU sed source or test files are included.
- `args` (optional): extra arguments passed to sed, one per line.
- `expected.bin`, `expected.json`, and `profile.json` are generated by `tools/gen-fixtures.sh`, which runs GNU sed. Do not edit them by hand.
- Generation runs under `LC_ALL=C`. The reference sed version is recorded in `profile.json`.

```sh
tools/gen-fixtures.sh                    # regenerate every fixture
tools/gen-fixtures.sh s-literal-global   # regenerate one
```
