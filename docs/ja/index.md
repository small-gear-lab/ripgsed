# ripgsed

sed の言語を保ちつつ、構文・意味論・実行方式を分離する Rust 製のストリームエディタ。

**状態: GNU sed 4.9 と GNU grep（3.x）に互換。ライブラリとしても、コマンドとしても使えます。**
